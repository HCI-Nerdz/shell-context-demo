== Run locally

[source,bash]
----
pnpm install
pnpm dev
----

Opens http://localhost:5175/ (Vite dev server).

== Demo controls

* **Left-arrow** ? cycle token focus (path ? user ? host ? app tokens)
* **Right-arrow / Enter** ? return toward input
* **PgUp / PgDn** ? scroll paste preview (5 visible lines)
* **Theme** button ? blue/grey default vs high-contrast
* **?** gutter ? static prohelp placeholder (no backend)
